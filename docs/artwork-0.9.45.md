# Artwork added for web release 0.9.45

- `camping-fire.webp`: first-person view of leather boots beside a stone-ring campfire at night, full-screen story illustration.
- `kobold-snare.webp`: cave scene showing a trapped adventurer hanging from a rope while kobolds jeer below.
- `shipyard-*.webp`: eight distinct coastal shipyards, each with a suspicious pirate harbormaster of a different age and appearance.
- `royal-doorway.webp` and `royal-intro-6.webp`: revised opening scenes with the player character's face fully concealed by a hood.
- `shrine-blob-statue.webp`: Oozul statue revision with reddish irises.

All generated artwork was composed for the existing painterly fantasy game style and stored as optimized WebP assets under `public/assets`.
