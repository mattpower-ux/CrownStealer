# Bar the Gates 0.9.52

Release 0.9.52 removes generic kobold guardians from Whispering Barrens lairs. Every guarded lair in that land now draws its fixed guardian from the infernal roster and retains the `demon` combat classification.

- Android version code 71.
- Offline cache generation `embers-v213`.
- Existing package identity and signing key retained.
- Browser saves and installed Android app data remain compatible.
