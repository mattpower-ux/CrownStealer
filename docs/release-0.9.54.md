# Bar the Gates 0.9.54

Release 0.9.54 rebuilds the abandoned estates as decayed aristocratic mansions. Their halls now use pale masonry, depth-occluded rib vaults, broken stained glass, vine-covered pillars, soft window light, fallen marble, distant chandeliers and fountains. Cellars remain darker service spaces with casks and damp stone.

Cave-troll groups now draw from three reusable individual variants: an eyepatched leader, a shaggy club brute and a scarred fist fighter. The variants can appear independently in later encounters rather than existing only as a single group illustration.

- Android version code `73`.
