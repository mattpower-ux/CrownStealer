# Bar the Gates 0.9.53

Release 0.9.53 polishes dungeon and world-map scenery. Tumbled Shrines gain Romanesque column-and-frieze walls with fallen column fragments, Stonefather floors use finer rubble sampling, cemetery markers become detailed graveyard vignettes, and the obsolete red line overlays are removed.

Troll caves now hold stable groups of two or three trolls. Dungeon creatures share the scenery floor projection, keeping their feet planted on the floor at every combat distance.

- Offline cache generation `embers-v214`.
- Android version code `72`.
